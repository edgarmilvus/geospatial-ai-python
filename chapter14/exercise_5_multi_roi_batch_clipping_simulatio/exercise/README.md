# Exercise 5 — one raster, three ROIs, three named tiles

## What it does

Simulates the batch job a training set comes from: a 250 × 250 pixel scene covering
0..25 degrees is opened once, and three ROIs from a GeoDataFrame — `A001`, `B002`,
`C003` — are cut out of it in a loop. The output name is built from the feature's
`id`, so `clipped_tile_A001.tif` is traceable back to its row, and the loop's inner
`try/except` reports a failed ROI without stopping the batch.

## The listings

| file | what it is |
| --- | --- |
| `01_batch_clip_rois.py` | the listing: the scene, the three ROIs, the batch loop, the per-tile log |
| `run_batch_clip_rois.py` | the harness: 30 assertions on the three windows, their bounds and their values |

## Run it

```bash
cd chapter14/exercise_5_multi_roi_batch_clipping_simulatio/exercise/files
python3 01_batch_clip_rois.py
```

It writes the scene and one GeoTIFF per ROI, logging each id before the cut and each
file after it; `run_batch_clip_rois.py` asserts that the three tiles hold 40 × 40,
50 × 50 and 50 × 50 pixels on their own ROI bounds, that the total is 6 600 pixels,
and that each tile is the scene's own window rather than a copy of the scene.

```text
Input scene: large_satellite_image.tif (250 x 250 px, 0-25 degrees)

Processing ROI ID: A001...
  -> SUCCESS: Tile saved as clipped_tile_A001.tif (40 x 40 px)

Processing ROI ID: B002...
  -> SUCCESS: Tile saved as clipped_tile_B002.tif (50 x 50 px)

Processing ROI ID: C003...
  -> SUCCESS: Tile saved as clipped_tile_C003.tif (50 x 50 px)

Batch complete: 3 of 3 ROIs clipped, 6600 pixels across the tiles.
```

## What it produces

| path | what it is |
| --- | --- |
| `output/large_satellite_image.tif` | the 250 × 250 px scene the ROIs are cut from, NoData −1 |
| `output/clipped_tiles/clipped_tile_A001.tif` | the 1..5 degree ROI, 40 × 40 px |
| `output/clipped_tiles/clipped_tile_B002.tif` | the 10..15 degree ROI, 50 × 50 px |
| `output/clipped_tiles/clipped_tile_C003.tif` | the 20..25 degree ROI, 50 × 50 px |
| `output/batch_clip_rois.json` | each tile's shape, pixel count and bounds, and the 6 600 total |

## Notes

- The scene exists because the book's version pointed at
  `path/to/large_satellite_image.tif` and left the call commented out. It is now
  generated by `build_demo_raster` from the same module, so the batch has something
  to cut.
- One degree is ten pixels here (0.1 degrees per pixel), which is why the ROIs
  produce 40 × 40 and 50 × 50 rather than an arbitrary size: the geometry decides the
  window, the resolution decides how many pixels fit in it.
- `os.makedirs(TILE_DIR, exist_ok=True)` runs at import, so a failed batch still
  leaves a writable folder for the error log to point at.

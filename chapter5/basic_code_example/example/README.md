# Basic code example — a GeoAxes, and the projection that must agree with the data

## What it does

Builds a 58-polygon world in WGS 84 and plots it on a Cartopy `GeoAxes` created with
`projection=ccrs.PlateCarree()`: a labelled graticule every 30 degrees of longitude and 20 of
latitude, an extent of ±180° by ±90° set in the data's own CRS, and a title that states the
example's claim — the data's CRS and the axes' projection are the same, so nothing is transformed
and nothing is distorted. The listing also prints the facts the axes now holds: its type, its
projection, its extent and how many graticule labels it produced.

## The listings

| file | what it is |
| --- | --- |
| `01_plate_carree_world.py` | the listing: the frame, the `GeoAxes`, the graticule, the PNG |
| `run_plate_carree_world.py` | the harness: projection class, extent, graticule labels, file size |

## Run it

```bash
cd chapter5/basic_code_example/example/files
python3 01_plate_carree_world.py
```

It builds the 58-cell world, draws it on a Plate Carrée `GeoAxes` with labelled gridlines and saves
`output/plate_carree_world.png`, printing the CRS, the bounds, the axes type, its projection and the
number of graticule labels. `run_plate_carree_world.py` asserts that the axes is a `GeoAxes` with
`ccrs.PlateCarree()`, that it spans ±180°/±90°, that Plate Carrée maps a degree to a degree
unchanged, and that the labels carry N/S and E/W; it exits non-zero when any of that changes.

```text
Polygons: 58
CRS: EPSG:4326 (WGS 84)
Type: GeoAxes
Projection: PlateCarree (+ellps=WGS84 +a=6378137.0 +proj=latlong +pm=0.0 +no_defs)
Extent (degrees): (-180.0, 180.0, -90.0, 90.0)
Gridline labels drawn: 7 along the bottom, 5 along the left
```

## What it produces

| path | what it is |
| --- | --- |
| `output/plate_carree_world.png` | the map on a Plate Carrée `GeoAxes`, 150 dpi |
| `output/plate_carree_world.json` | axes type, projection, extent, CRS, label counts, PNG size |

## Notes

- One substitution: the bundled `naturalearth_lowres` dataset was removed in GeoPandas 1.0, so the
  world is a fixed 58-cell land mask, generated by the listing. The `GeoAxes`, the projection and
  the graticule are the book's own code, unchanged.
- `ax.coastlines(resolution='50m')` is deliberately **not** used: it downloads a Natural Earth
  shapefile on first run. The land polygons are already on the axes, so their edges play the part.
- `gl.top_labels = False` and `gl.right_labels = False` are Cartopy 0.26's own attributes; the
  harness checks that the top and right edges stayed empty.
